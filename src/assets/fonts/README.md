# Fonts for generated preview images

Used only at build time by `src/pages/og/[...slug].png.ts` to draw text into the link-preview PNGs.
The live site loads the same families from Google Fonts.

| File | Family | Licence |
| --- | --- | --- |
| SpaceGrotesk-Bold.ttf | Space Grotesk (Florian Karsten) | SIL Open Font License 1.1 |
| Inter-Regular.ttf, Inter-SemiBold.ttf | Inter (Rasmus Andersson) | SIL Open Font License 1.1 |
| SpaceMono-Regular.ttf | Space Mono (Colophon Foundry) | SIL Open Font License 1.1 |

Downloaded as static per-weight TTFs (Latin subset) from the Fontsource CDN.
The OFL allows bundling and redistributing the fonts with software; they may not be sold on their own.
Full licence text: https://openfontlicense.org
